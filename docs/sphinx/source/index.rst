Welcome to AQUA-claima's documentation!
=======================================

AQUA-claima ships the configuration and the tools of the CLAIMA project for the
`AQUA <https://aqua.readthedocs.io/en/latest/index.html>`_ framework, as an aqua-core project plugin.
Installation and the analysis configuration are described in the ``README.md`` of the
`repository <https://github.com/AQUA-friends/AQUA-claima>`_; this documentation is a first draft
and covers only the catalog generators for now.
